A travel poster for **Solmere**, a coastal town that does not exist: a low
golden sun over a calm sea, one spiral beacon tower as the single landmark,
white rooftops along the shore, and small sailboats at anchor. The invented
name is the only text in the picture.

`main.py` renders the poster with the Python standard library only — a
hand-rolled PNG encoder and bitmap font, pure-math drawing, fully
deterministic. Running it writes a 1024×1024 PNG to `/output/entry.png`.

```sh
python3 main.py
```
